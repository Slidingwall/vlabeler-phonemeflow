## Labeling lines / 标注线

For each phoneme, there are four annotation points: `[Start, Stable Start(SS), Stable End(SE), End]`.  
对于每个音素，共有`[起始, 稳定段起始, 稳定段终止, 终止]`4个标注点。  
![](/assets/main.webp)  

For vowels, the stable segment should cover the entire medials, while initials and endings should not. For example, in the `iong`, the stable segment only covers `-o-`, while `io-` and `-ong` are not included.  
对于元音，稳定段起始与稳定段终止要覆盖整个韵腹部分，介音与尾音不应该包含在其中。例如此处的`iong`，稳定段仅覆盖`-o-`，而`io-`和`-ong`则不被包含在内。  
对于辅音，爆破音的稳定段为前半段，其他辅音的稳定段为后半段。对于已经支持的语言，程序会根据辅音性质自动选择前半段或后半段作为稳定段，从而忽略稳定段起始或终止的设置。  
For consonants, the stable segment for plosives is the first half, and for other consonants, it's the second half. For supported languages, the program will automatically choose the first half or the second half as the stable segment, ignoring the settings for stable segment start or end.  
![](/assets/example.webp)
