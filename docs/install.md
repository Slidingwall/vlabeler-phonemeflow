# Install / 安装

First, you need to locate the installation directory of vlabeler phonemizer and its plugins. In vlabeler, click `Help -> Open Log Directory`.  
首先，您需要找到vlabeler音素器与插件的安装目录。在vlabeler中，点击`帮助->打开日志目录`。  
![](/assets/IN1.webp)  

After opening the log directory, open its parent directory.  
打开日志目录后，再打开它的上级目录。  
![](/assets/IN2.webp)  

In the parent directory, you can see the `labelers` and `plugins` folders.  
在上级目录中，您可以看到`labelers`和`plugins`文件夹。  
![](/assets/IN3.webp)  

Put the `labelers/plugins` folder in this directory.  
将`labelers/plugins`文件夹放在这个目录中。  
![](/assets/IN4.webp)  

In vlabeler, click `Settings -> Labelers…` to check whether the labeler is imported correctly.  
在vlabeler中，点击`设置->标注器…`以检查标注器是否导入正确。  
![](/assets/IN5.webp)  

Click `Tools -> Batch Edit -> Manage Plugins…` to check whether the plugins are imported correctly.  
点击`工具->批量编辑->管理插件…`以检查插件是否导入正确。  
![](/assets/IN6.webp)
