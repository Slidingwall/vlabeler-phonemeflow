# vlabler-phonemeflow

Experimental labeler for UTAU/DeepVocal/VocalSharp/Vocaloid etc in vLabeler, still in development.  
Using scripts to export separated labeling lines from a continuous labeling file.  

vLabeler 中用于 UTAU/DeepVocal/VocalSharp/Vocaloid 等软件的实验性标注器，仍在开发中。  
采用脚本从连续的标注文件中导出分离的标注行。  

Put the `labelers/plugins` folder in `[username]\vlabeler`.  
When exporting, use the `phonemeflow-exporter` plugin.  

将`labelers/plugins`文件夹放在`[用户名]\vlabeler`中。  
导出时，请使用`phonemeflow-exporter`插件。
